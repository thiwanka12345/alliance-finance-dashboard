# 📊 Alliance Finance Company PLC - CEO Dashboard

An interactive Executive Performance & 5-Year Outlook Dashboard built with **Streamlit**, **Pandas**, and **Plotly**. This dashboard provides key insights into profitability, balance sheet growth, capital adequacy, risk-adjusted returns (Sharpe Ratio), and future asset projections for Alliance Finance Company PLC (2023–2026).

---

## 🚀 Features

* **Top Executive KPIs:** Real-time metrics for Profit After Tax (PAT), Total Assets, and Return on Equity (ROE).
* **Financial Growth Analytics:** Dynamic visual comparisons between Revenue (Net Interest Income) and PAT.
* **Ratio Analysis:** Dual-axis visualization for Profitability (ROE vs. ROA) and Asset Quality/Solvency (NPL vs. CAR).
* **Risk & Sharpe Ratio Analysis:** Evaluates risk-adjusted returns using volatility and excess return over risk-free rate.
* **5-Year Asset Forecast:** Dynamic dynamic projection tool estimating asset growth trajectory over a 5-year horizon.

---

## 🛠️ Tech Stack

* **Language:** Python
* **Dashboard Framework:** Streamlit
* **Data Manipulation:** Pandas
* **Data Visualization:** Plotly Express & Plotly Graph Objects
